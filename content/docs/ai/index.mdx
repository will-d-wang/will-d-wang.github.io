# AI for Engineering

AI can help draft code, explain unfamiliar systems, and explore options. Treat its output as a proposal that still needs tests, review, and an owner. The useful question is whether a workflow becomes clearer or faster without weakening its checks.

## Follow this path

1. **[Read the AI-assisted development field note](/field-notes/ai-assisted-development)** for a practical workflow with verification steps.
2. **[Review software testing notes](/docs/DevSecOps/process/3.test)** to decide what evidence a generated change needs.
3. **[Study search in artificial intelligence](/docs/OMSCS/CS6601-Artificial-Intelligence/1.Search)** for broader context.

## Put it into practice

Use an assistant to propose one small improvement to the [service lab](/labs/build-and-operate-a-service), such as a clearer health response or a deployment check. Write the expected behavior first. Run the service and compare the result with the expectation before accepting the change.
