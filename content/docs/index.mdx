# Learn

This is a map through the notes on this site. Pick a discipline below, or follow the [build and operate a service lab](/labs/build-and-operate-a-service) if you learn best by doing. Older notes remain available in the sidebar; the paths below select a useful starting point from them.

## Choose a path

- **[SRE](/docs/sre):** Observe a service, reason about reliability, and prepare for operational work.
- **[Infrastructure](/docs/infrastructure):** Understand the cloud and Kubernetes layers that run a service.
- **[DevOps](/docs/devops):** Build, test, and release changes with a short feedback loop.
- **[Platform Engineering](/docs/platform):** Make reliable delivery easier for other developers.
- **[AI for Engineering](/docs/ai):** Apply AI to engineering tasks and verify the results.

## How to use the site

The [Labs](/labs) section gives you something to run. [Field Notes](/field-notes) explain the decisions and tradeoffs behind the work. Existing technical notes stay at their original URLs so bookmarks and links continue to work.
