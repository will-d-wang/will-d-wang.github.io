# Labs

These exercises turn the learning paths into something you can run. Each lab includes an expected result and a cleanup step. Use a local environment first; the goal is to see the mechanics before adding cloud-specific choices.

## Start with a service

**[Build and operate a service](/labs/build-and-operate-a-service)** — create a small HTTP service, package it in a container, deploy it to a local Kubernetes cluster, verify readiness, and practice a change. You will need Python 3, Docker, kind, kubectl, and a terminal.

When you finish, connect the exercise to the [DevOps path](/docs/devops) for CI/CD decisions, the [Infrastructure path](/docs/infrastructure) for deployment choices, and the [SRE path](/docs/sre) for reliability questions.
